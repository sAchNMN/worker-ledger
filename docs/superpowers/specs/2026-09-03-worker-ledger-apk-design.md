# 打工人小账本：离线 Android APK 设计

## 1. 目标与边界

构建一个名为“打工人小账本”的可直接安装 Android APK，复刻参考页面的核心信息架构与奶油薄荷手账风，用于个人离线记录收入、支出和时间成本。

明确边界：

- 不登录、不联网、不接入远程数据库。
- 所有数据只存放在应用私有目录的 SQLite 数据库中。
- 不申请网络权限；换设备不会自动同步，只能通过 JSON 备份迁移。
- 首次安装显示空白账本，不写入演示流水，避免污染真实数据。
- 交付个人侧载可用的 `app-debug.apk`；正式商店签名不在本次范围内。

## 2. 技术架构

采用“原生 Java Android 壳 + APK 内嵌 WebView 页面”的最小架构：

- Android 原生层负责 Activity、SQLite、系统文件选择器、导入导出和 JavaScript Bridge。
- WebView 负责响应式界面、计算展示、原生 SVG 图表和页面交互。
- 页面资源随 APK 打包在 `assets/`，用 `file:///android_asset/` 加载，不依赖网络。
- 不引入第三方 UI、图表或数据库依赖，降低离线构建失败风险。
- Android 最低版本定为 API 24（Android 7.0），目标版本使用本机可用的 Android SDK。

原生层与页面层之间只暴露本地数据操作：读取全部数据、保存设置、新增流水、更新流水、删除流水、导出 JSON、导入 JSON。Bridge 仅对 APK 内置页面启用，不加载外部 URL。

## 3. 数据模型

### 3.1 `ledger_entries`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | 本地唯一 ID |
| `kind` | TEXT NOT NULL | `income` 或 `expense` |
| `amount_cents` | INTEGER NOT NULL | 以分存储，避免浮点误差 |
| `category` | TEXT NOT NULL | 分类名称 |
| `note` | TEXT | 备注 |
| `entry_date` | TEXT NOT NULL | `YYYY-MM-DD` |
| `expense_type` | TEXT | `fixed`、`flexible`；收入为空 |
| `created_at` | INTEGER NOT NULL | Unix 毫秒时间戳 |
| `updated_at` | INTEGER NOT NULL | Unix 毫秒时间戳 |

默认支出分类为：吃饭、交通、购物、娱乐、房租、其他。默认固定分类为房租，其余默认弹性；编辑流水时可覆盖固定/弹性。默认收入分类为奖金、兼职、礼金、其他；工资收入来自设置，不强制重复记账。

### 3.2 `user_settings`

使用单行设置记录：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PRIMARY KEY | 固定为 1 |
| `monthly_take_home_cents` | INTEGER NOT NULL | 综合到手月薪 |
| `pay_months` | REAL NOT NULL | 发薪月数，默认 12 |
| `workdays_per_month` | REAL NOT NULL | 每月工作日，默认 21.75 |
| `onsite_hours_per_day` | REAL NOT NULL | 每日在场时长，默认 8 |
| `commute_hours_per_day` | REAL NOT NULL | 每日往返通勤时长，默认 1 |
| `overtime_hours_per_month` | REAL NOT NULL | 每月加班时长，默认 0 |
| `work_cost_cents_per_month` | INTEGER NOT NULL | 每月工作成本，默认 0 |
| `fund_goal_cents` | INTEGER NOT NULL | 自由基金目标 |
| `fund_current_cents` | INTEGER NOT NULL | 当前已存金额 |
| `updated_at` | INTEGER NOT NULL | 更新时间 |

## 4. 计算规则

所有金额在原生层以整数分保存，页面展示时转换为元；时长以分钟或小时的小数计算，结果统一四舍五入展示。

```text
年度收入 = 综合到手月薪 × 发薪月数
年度工作成本 = 每月工作成本 × 12
年度时间成本 =
  (每月工作日 × (每日在场时长 + 每日通勤时长)
   + 每月加班时长) × 12
真实时薪 = (年度收入 - 年度工作成本) ÷ 年度时间成本
一笔支出对应工时 = 支出金额 ÷ 真实时薪
```

发薪月数只影响年度收入，不影响一年实际工作时间。加班单独计入时间成本。真实时薪分母为 0 或设置非法时，显示“请先完善时薪参数”，不显示无穷或错误数值。

月度总结按所选月份计算：

```text
工资收入 = 综合到手月薪（仅当该月有效）
额外收入 = 当月 kind = income 的流水合计
总收入 = 工资收入 + 额外收入
固定支出 = 当月 expense_type = fixed 的流水合计
弹性支出 = 当月 expense_type = flexible 的流水合计
月度结余 = 总收入 - 固定支出 - 弹性支出
```

自由基金安全垫月数使用当前月份总支出作为基准；没有支出样本时显示“暂无支出样本”，不伪造月数。存款曲线使用当前余额加上当前月度结余做未来 6 个月投影，低于 0 时按 0 展示，并以原生 SVG 绘制。

## 5. 页面与交互

### 5.1 今日驾驶舱

- 显示真实时薪、本月支出、自由基金进度。
- 显示最近 4 笔流水。
- 提供“现在记一笔”快速表单。
- 保存支出成功后立即显示“金额 ≈ 工作 X 小时 Y 分钟”。

### 5.2 我的时薪

- 编辑全部时薪参数与工作成本。
- 展开公式，展示每一项输入如何参与计算。
- 保存成功后回写 SQLite，并刷新所有页面的换算结果。

### 5.3 10 秒记账

- 收入/支出切换。
- 金额、分类、备注、固定/弹性、日期。
- 支出默认按分类自动归类，用户可以修改；收入不显示固定/弹性选项。
- 支持编辑和删除，删除前二次确认。

### 5.4 月度总结

- 月份选择器。
- 工资收入、额外收入、总收入、固定支出、弹性支出、结余。
- 支出分类分布和流水列表，适合触屏点击编辑。

### 5.5 自由基金

- 自由基金目标金额与当前余额。
- 进度、剩余金额、安全垫月数。
- 原生 SVG 存款曲线。

### 5.6 有趣发现

- 通勤情景：调整每日通勤时长，比较真实时薪与年度时间成本。
- 加班情景：调整每月加班时长，按“默认无额外加班费”估算，比较真实时薪。
- 涨薪情景：调整月薪涨幅，比较真实时薪与月度结余。
- 每个情景同时显示基线与模拟值，避免只给百分比而不展示绝对值。

### 5.7 响应式布局与视觉

- 手机使用底部 Tab：今日、时薪、记账、月结、自由、发现。
- 宽屏使用侧栏导航。
- 奶油底色、薄荷主色、柔和珊瑚色强调、圆角卡片和清晰的触屏点击区域。
- 图标全部使用内联 SVG；小猪存钱罐使用内联 SVG，避免外部图片依赖。
- 支持浅色/深色切换，颜色使用 CSS 变量集中管理。

## 6. 错误处理与数据安全

- 页面启动先渲染布局和加载状态，再调用 Bridge 读取数据。
- SQLite 读取失败：显示错误卡片和“重试”，页面不白屏。
- 新增、编辑、删除写入失败：保留草稿或当前列表，不显示成功状态，并提供重试。
- 导入先解析、校验版本和字段范围，全部通过后在 SQLite 事务中替换；失败则保留原数据。
- 导出失败显示系统错误信息；成功后提示文件位置。
- 数值输入在页面和原生层双重校验；金额使用整数分；数据库写入使用事务。
- 不声明 `INTERNET` 权限，不访问外部 URL。

## 7. 验证与交付

验证至少覆盖：

1. 计算自检：默认参数的真实时薪、支出换算和边界值。
2. 数据自检：新增、读取、编辑、删除、重启后数据仍存在。
3. 导入导出：合法 JSON 可还原，非法 JSON 不覆盖原账本。
4. 交互自检：启动、切 Tab、提交失败提示、重试、删除确认。
5. 响应式检查：手机宽度和宽屏宽度布局均可用。
6. `assembleDebug` 构建成功，生成可安装 APK。

最终交付：`app/build/outputs/apk/debug/app-debug.apk`，并附带手机安装与 JSON 备份使用说明。
