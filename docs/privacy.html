打工人小账本 隐私政策

适用应用：打工人小账本（worker-ledger）　包名：com.workerledger.app　版本：1.0

核心承诺：本应用不联网，不收集、不上传、不共享任何个人信息。 应用未申请网络权限，不具备访问互联网的能力；所有流水、工资设置与统计数据仅保存在你的手机本地，开发者无法读取，也无法获取。

一、我们收集哪些个人信息

不收集任何个人信息。本应用不收集、不使用、不存储以下任何一类信息：

  • 身份信息（姓名、身份证号、手机号、邮箱、账号密码等）
  • 设备信息（设备型号、系统版本、IMEI、OAID、MAC 地址、Android ID 等）
  • 位置信息（GPS、基站、WiFi 等任何形式的定位）
  • 通讯录、短信、通话记录、相册、麦克风、摄像头内容
  • 应用列表、剪贴板、已安装应用与使用行为数据
  • 你在应用内填写的记账金额、分类、备注、工资参数

你在应用内填写的财务数据属于本地数据而非个人信息收集：它只写入手机本地的应用私有数据库，不会离开你的设备。

二、应用申请的权限

本应用未申请任何 Android 系统权限，包括但不限于：

权限是否申请说明
INTERNET（网络访问）不申请应用无联网能力，无法上传任何数据
存储 / 相册读写不申请导出与导入备份通过系统文件选择器完成，由你主动指定文件位置，无需授权
位置、相机、麦克风、通讯录、通话、短信不申请应用无相关功能
读取应用列表 / 设备标识不申请应用不获取任何设备标识符

你不必在系统设置中为本应用开启任何权限开关，应用即可正常使用全部功能。本应用也不存在强制、频繁、过度索取权限的行为。

三、数据存放位置

  • 记账流水、分类模板、工资历史与个人设置，全部写入手机本地 SQLite 数据库（应用私有目录）。
  • 该目录仅本应用可读写，其他应用与开发者均无法访问。
  • 数据不依赖浏览器缓存，不使用 Cookie 或类似跟踪技术，不进行任何埋点统计。

四、数据的共享、转让与公开披露

本应用不存在以下行为：

  • 向任何第三方（含开发者、关联公司、广告商、数据分析机构）共享、转让或出售你的数据；
  • 将你的数据用于广告投放、用户画像、精准营销或个性化推荐；
  • 公开披露你的任何数据。

因应用不具备联网能力，上述行为在技术上亦无法发生。

五、第三方 SDK 与外部服务

本应用未集成任何第三方 SDK：无统计分析 SDK、无广告 SDK、无推送 SDK、无崩溃上报 SDK、无社交登录与支付 SDK。应用全部功能基于 Android 系统原生接口实现。

六、备份与导出

应用提供"导出备份"与"导入备份"功能，用于你自行跨设备迁移数据：

  • 导出为你主动触发的本地操作，生成 JSON 文件并保存至你选定的位置；
  • 应用不会自动上传、自动同步或自动备份任何数据；
  • 导出文件离开应用后的存放、分享与保管由你自行决定，请你妥善保管；
  • 导入时文件仅在本机校验与读取，取消或校验失败都不会覆盖你现有的数据。

七、系统备份与自动同步

  • 本应用已关闭 Android 系统自动备份（android:allowBackup="false"），你的应用数据不会被系统备份到云端或在换机时自动恢复。
  • 本应用不提供云同步，也不提供跨设备自动同步；跨设备迁移必须由你手动导出、导入备份文件。
  • 本应用无自启动行为、无后台静默运行、无关联启动，退出后不会在后台收集任何信息。

八、数据的删除

  • 在应用内删除单条记录或清空数据，会立即从本地数据库移除对应内容。
  • 卸载本应用，或执行系统"清除应用数据"，即彻底删除全部本地数据，不可恢复。
  • 由于数据始终只存在于你的设备本地，不存在需要向开发者申请删除的云端副本。你无需提出任何删除请求，卸载即完成删除。

九、未成年人保护

本应用为本地记账工具，不含社交、广告、付费、抽奖与个性化推荐功能，不收集任何个人信息，亦不会出现任何诱导性内容。未成年人可在监护人指导下使用。

十、信息安全

你的数据仅保存在应用私有目录中，受 Android 系统应用沙箱保护，其他应用无法读取。由于数据不经过网络传输，不存在传输环节的泄露风险。请你自行妥善保管导出的 JSON 备份文件及手机解锁凭据。

十一、本政策的变更

若本政策发生变更，更新后的版本将在本页面公示并同步修改页面顶部的更新日期。若应用未来新增任何涉及数据收集的功能，我们会在版本更新前明确告知你，并重新征求你的同意。
